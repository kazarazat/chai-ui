# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good intent, and keep discussion about the
work. Harassment of any kind isn't tolerated.

Report unacceptable behavior privately through GitHub's
[private reporting](https://github.com/kazarazat/chai-ui/security/advisories/new)
or by contacting the maintainer, @kazarazat. Reports are kept confidential.
